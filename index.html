Présentation

Ce widget Grist permet de générer des documents PDF ou ODT à partir d'un modèle HTML stocké dans la table Modeles et des données de la table courante.

Configuration requise

  • La table doit avoir une colonne HTML (formule) mappée dans le panneau de configuration du widget.
  • Une table Modeles doit exister avec une colonne Nom_du_modele.
  • La table doit avoir une colonne Modele (référence vers la table Modeles).
  • La colonne Nom_fichier est utilisée pour nommer les fichiers générés.

Impression unitaire Onglet Unitaire

  • Cliquez sur une ligne dans la table Grist.
  • Choisissez un modèle dans la liste déroulante.
  • Cliquez sur Télécharger PDF ou Télécharger ODT.
  • Le modèle est appliqué temporairement, le document généré, puis la valeur précédente est restaurée.

Impression en lot Onglet En lot

  • Choisissez un modèle.
  • Cochez les lignes à inclure dans le lot (Tout sélectionner / Tout désélectionner).
  • Cliquez sur ZIP de PDF ou ZIP de ODT.
  • Un fichier ZIP contenant tous les documents est téléchargé automatiquement.

Notes importantes Attention

  • Ne pas fermer ou recharger la page pendant la génération.
  • Pour des lots importants (100+ lignes), prévoir 2 à 3 minutes de traitement.
  • Le format ODT est compatible LibreOffice. Le logo et les images sont embarqués.
  • La police Marianne doit être installée sur le poste pour apparaître dans le ODT.
